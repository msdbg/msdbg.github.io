
# Mapping the Tools: the MITRE ATT&CK Tools Mindmap

What's good people, it's msdbg back with a new project! 

you might have wondered *“Okay, I know this MITRE technique, but what specific tool actually executes this? And what is the command syntax?”* 
So here we are. Basically, I was making tool lists and jotting down different tools and commands. As the list got big and unorganized, I decided to use the MITRE ATT&CK framework as a reference. Then, with the help of AI, I created a mindmap for it, i found it somewhat useful so i decided to publish it.

## What is it?

The MITRE ATT&CK Tools Mindmap visually maps over **1,000+ specific tool examples with commands** directly to the MITRE ATT&CK framework. 
![alt text](mitre-attack-toolmap.png)



## The Real problem
Each Technique is mapped to the most relevant tool with confidence rating and also provides the exact command example/usage
